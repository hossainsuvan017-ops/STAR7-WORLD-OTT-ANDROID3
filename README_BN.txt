APPLICATION INFORMATION
-----------------------

STAR 7 WORLD OTT is an OTT application project.

The Android application uses a WebView to
display the HTML interface.

The main HTML application is located at:

app/src/main/assets/index.html

Minimum SDK: 26

BUILD APK
---------

1. Open the Android project in Android Studio.

2. Allow Gradle synchronization to finish.

3. Select Build.

4. Select Build APK(s).

5. Wait for the build to finish.

6. Find the generated APK in:

app/build/outputs/apk/debug/


IMPORTANT NOTES
---------------

1. The HTML application runs inside Android WebView.

2. A production backend is not included.

3. Real subscription payments are not configured.

4. Google Play Billing is not integrated.

5. Admin security requires a secure backend.

6. Online video streaming requires hosting
   and appropriate content rights.

7. Keep backups of your project.

8. Test all features before publishing.
